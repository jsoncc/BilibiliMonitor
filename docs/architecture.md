# 架构说明

前端 Vue 3 负责展示和每分钟刷新；FastAPI 负责解析输入、调用数据源、保存快照和提供趋势 API；APScheduler 在后端进程内执行自动采集；SQLite 保存项目目录 `data/` 下的历史数据。

数据流：浏览器输入 → 后端预览 → 用户确认 → 数据源适配器 → 成功快照入库 → 趋势 API → ECharts。仅查看一次走临时查询链路，不进入监控任务。监控任务不依赖浏览器页面持续打开，只依赖后端进程运行。

采集任务使用每对象异步锁避免重复采集；失败最多重试两次，退避 5 秒和 15 秒，最终失败记录日志并延长下一次采集时间。

没有历史快照的对象会从首次成功采集时间开始形成趋势。采集失败不会写入快照。
