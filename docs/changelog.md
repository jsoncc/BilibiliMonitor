# 变更记录

## 2026-09-13

- 增加单对象沉浸式专注模式；按对象保存指标配置，隐藏其他对象和非指标操作，视频三连总量明确为点赞、投币、收藏之和。
- 指标卡增加新快照到达时的数字滚动与高亮反馈。
- 重做专注模式 KPI 视觉层级：单指标使用主卡片，多指标自动切换紧凑网格，并补充周期变化与数据新鲜度信息。
- 专注模式调整为全屏数据展示层，移除非数据页面元素并弱化返回操作。
- 恢复专注模式右上角的轻量配置入口，支持随时调整已保存指标。
- 强化专注模式变化量：增加本次采集、近 24 小时、近 7 天的绝对变化、百分比和实际覆盖时间。

- 增加 CSV/JSON 快照导出、本地数据容量摘要、对象采集记录和 SQLite WAL 并发读取优化。

- 移除受平台访问限制的 WBI 投稿日期采集、状态字段和页面指标。
- UP 主监控范围调整为粉丝、投稿数和关注数；历史数据库字段保留但不再读写。
