# 产品需求文档（PRD）

## 1. 产品目标

BilibiliMonitor 是一个本地运行的轻量 B 站数据监控工具。用户输入视频或 UP 主标识后，可以查看当前数据、历史采集趋势，并选择是否加入后台自动监控。

## 2. 核心用户流程

1. 首屏只显示搜索框，不预先堆积数据。
2. 输入 BV/AV、视频链接、UID 或空间链接。
3. 系统解析并展示对象预览。
4. 用户选择开始后台监控、仅查看一次或取消。
5. 已监控对象持续自动采集；页面每分钟刷新。
6. 用户可停止监控，历史快照不删除。

## 3. 功能范围

### 页面结构与交互

- 采用浅色专业工作台布局：顶部搜索、左侧监控导航、右侧单对象详情。
- 左侧分为“正在监控”和“历史记录”，对象显示缩略图、标识、状态和最后采集时间。
- 详情区按身份、指标、采集控制、趋势顺序展示，避免不同数量级指标同时挤在一张图中。
- 趋势支持 24 小时、7 天、30 天；默认单指标查看，并支持增量/总量切换。
- 无数据、单点数据和采集失败均显示明确说明，不使用空白图表或浏览器原生弹窗。

### 视频监控

- 播放量、点赞、投币、收藏、评论、弹幕、在线人数。
- 当前值、采集时间、增长量。
- 默认展示最近 7 天趋势图，支持增量和总量模式。

### UP 主追踪

- 粉丝数、关注数、投稿数。
- 当前值、增长量和历史趋势。

### 采集管理

- 默认每 60 秒采集一次。
- 后端独立采集，不依赖浏览器页面打开。
- 支持停止监控，保留历史数据。
- 支持历史记录查看和恢复监控。
- 支持立即采集和采集间隔设置。

## 4. 非功能要求

- 本地运行，不依赖云服务。
- 所有代码、文档、数据库和配置位于项目目录内。
- 页面清爽、信息层次明确、错误信息可见。
- Cookie 等敏感配置不得提交到仓库或日志。

## 5. 暂不包含

按昵称搜索、全站采集、直播弹幕、AI 预测、复杂通知、多用户权限、云端部署和移动端 App。
