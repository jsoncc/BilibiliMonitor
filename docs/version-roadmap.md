# 版本规划

## v0.1 本地可运行 MVP

状态：核心功能已完成，体验和文档持续完善。

- [x] Vue + FastAPI + SQLite 基础工程
- [x] BV/AV/视频链接/UID/空间链接解析
- [x] 视频数据采集
- [x] UP 主信息和数据采集
- [x] 定时自动采集
- [x] 快照和趋势计算
- [x] 增量/总量图表
- [x] 停止监控二次确认
- [x] VS Code 启动配置
- [x] 搜索后的正式监控确认弹窗
- [x] 当前监控与历史记录独立展示
- [x] 仅查看一次不创建长期监控对象
- [x] 基础自动化测试
- [x] 手动采集和采集间隔设置
- [x] 采集重试与退避

## v0.2 可用性增强

- 采集状态、最后成功时间和失败次数展示。
- 页面手动立即采集按钮。
- 完善重试、限流和指数退避。
- 更详细的历史时间范围选择。
- 优化移动窗口下的布局。

## v0.3 稳定性和数据能力

- PostgreSQL 可选迁移方案。
- 更完善的任务调度和并发限制。
- 数据导出。
- 可配置通知。

## v1.0 可选上线版本

- 云服务器部署。
- 域名和 HTTPS。
- 后端进程守护。
- 访问认证和数据安全策略。
