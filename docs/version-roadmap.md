# 版本规划

## v0.1 本地可运行 MVP

状态：核心功能已完成，体验和文档持续完善。

- [x] Vue + FastAPI + SQLite 基础工程
- [x] BV/AV/视频链接/UID/空间链接解析
- [x] 视频数据采集
- [x] UP 主信息和数据采集
- [x] 定时自动采集
- [x] 快照和趋势计算
- [x] 增量/总量图表
- [x] 停止监控二次确认
- [x] VS Code 启动配置
- [x] 搜索后的正式监控确认弹窗
- [x] 当前监控与历史记录独立展示
- [x] 仅查看一次不创建长期监控对象
- [x] 基础自动化测试
- [x] 手动采集和采集间隔设置
- [x] 采集重试与退避
- [x] 专业化工作台布局与组件拆分
- [x] 当前监控/历史记录视觉分区
- [x] 趋势时间范围和单指标切换
- [x] 无数据、单点和失败状态提示
- [x] 首屏布局压缩与侧栏内部滚动
- [x] 趋势时间轴重复日期修复
- [x] B 站图片地址标准化和受限代理
- [x] 图片失败占位和统一按钮层级

## v0.2 可用性增强

- [x] CSV/JSON 导出当前对象和全部对象，支持时间范围筛选。
- [x] 本地数据库容量、快照数量、采集健康摘要和最近日志查看。
- [x] SQLite WAL 与 busy timeout，降低采集和导出并发冲突。
- 优化移动窗口下的布局。

## v0.3 稳定性和数据能力

- PostgreSQL 可选迁移方案。
- 更完善的任务调度和并发限制。
- 可配置通知。

## v1.0 可选上线版本

- 云服务器部署。
- 域名和 HTTPS。
- 后端进程守护。
- 访问认证和数据安全策略。
