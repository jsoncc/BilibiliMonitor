# 测试计划

## 自动化测试目标

- 输入解析：BV、AV、视频链接、UID、空间链接。
- 重复对象不会创建重复记录。
- 趋势增长计算正确。
- 采集失败不写入有效快照。
- 停止监控后任务不再执行。
- 历史快照仍可查询。
- 趋势 24 小时、7 天、30 天参数有效。
- 单指标切换不影响其他指标数据。
- 图片代理只允许 B 站图片域名，非法域名和空地址被拒绝。
- UP 主采集只调用公开关系统计与账号卡片接口，不发起 WBI 投稿请求。
- 导出范围解析、空快照 CSV/JSON 文件和快照字段序列化正确。

## UI 专项验收

- [ ] 搜索预览弹窗包含对象封面/头像、类型、标识和三个操作。
- [ ] 取消不改变监控列表，仅查看一次不写入长期监控。
- [ ] 当前监控和历史记录分区清晰，历史对象可恢复。
- [ ] 单点数据显示“等待下一次采集”，而不是空白图表。
- [ ] 切换时间范围、指标和增量/总量后图表与摘要同步变化。
- [ ] 采集失败显示最近成功时间和错误信息。
- [ ] 1366×768 和 1920×1080 首屏无需滚动查看主要内容。
- [ ] 趋势横坐标在 24 小时、7 天、30 天范围下不重复堆叠。
- [ ] 图片失败显示统一占位，按钮视觉和高度一致。
- [ ] 当前对象与全部对象的 CSV/JSON 下载、容量摘要和采集记录需通过浏览器手工验收。
