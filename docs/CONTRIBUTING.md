# BilibiliMonitor 贡献指南

## Commit message 规范

本项目采用 Conventional Commits 风格。提交第一行必填，正文和附加区块按需填写。

```text
<type>(<scope>): <中文简洁摘要>

[详细说明]

测试：
- [实际执行过的测试命令]

兼容性：
- [兼容性说明，可选]

BREAKING CHANGE：
- [不兼容变更说明，可选]

关联：
- [Issue、PR 或任务编号，可选]
```

### 第一行

- `type` 和 `scope` 使用英文，摘要使用中文。
- 摘要以动词开头，例如“增加”“修复”“调整”“补充”“统一”。
- 摘要简洁、准确，不以句号结尾，建议不超过 50 个中文字符。
- 一次提交只表达一个清晰目的，不堆叠无关改动。
- 不使用“修改了一些问题”“完善功能”等无法判断内容的描述。

示例：

```text
fix(frontend): 修复趋势图横坐标重复显示
feat(backend): 增加 B 站图片代理接口
docs(api): 补充图片代理接口说明
```

## Type 类型

| 类型 | 用途 |
| --- | --- |
| `feat` | 新增功能 |
| `fix` | 修复功能或缺陷 |
| `docs` | 修改项目文档 |
| `refactor` | 重构代码，不改变外部行为 |
| `perf` | 性能优化 |
| `test` | 新增或修改测试 |
| `build` | 构建配置、依赖或打包变更 |
| `ci` | CI/CD 配置变更 |
| `chore` | 其他维护性工作 |
| `revert` | 回滚已有提交 |

纯样式调整使用 `fix(frontend)` 或 `refactor(frontend)`，不单独增加 `style` 类型。

## Scope 作用域

作用域必须使用英文，并描述受影响的功能模块。

| Scope | 使用范围 |
| --- | --- |
| `frontend` | Vue 页面、组件、样式和前端交互 |
| `backend` | FastAPI、采集逻辑和后端服务 |
| `api` | API 路由、请求参数和响应结构 |
| `collector` | 定时采集、重试、退避和任务状态 |
| `database` | SQLite、模型、快照和数据库初始化 |
| `chart` | ECharts、趋势数据、时间轴和图表交互 |
| `media` | 图片地址、图片代理、封面和头像 |
| `docs` | 文档体系和说明文件 |
| `test` | 跨模块测试或测试基础设施 |
| `config` | VS Code、环境变量和项目配置 |
| `release` | 版本发布、打包和发布准备 |

## 正文规则

正文用于说明背景、问题、主要改动或实现原因。只有一条说明时可以直接写一段文字；多条内容使用编号，每项只描述一个独立事项。

```text
fix(chart): 修复历史趋势窗口过短问题

1. 将默认趋势窗口调整为最近 7 天。
2. 保留 24 小时和 30 天查询范围。
3. 增加趋势接口时间窗口测试。
```

## 测试区块

代码、接口或构建相关提交应记录实际执行过的验证命令。未执行的测试不得写入提交信息。

```text
测试：
- frontend: pnpm run build
- backend: python -m unittest discover -s tests -v
```

仅文档变更可以不填写测试区块；如果执行了文档检查，应记录实际命令。

## 兼容性和破坏性变更

以下情况必须增加 `兼容性：` 或 `BREAKING CHANGE：`：

- API 请求参数或响应结构变化。
- 数据库字段、快照结构或迁移方式变化。
- 删除已有接口或前端操作。
- 调整运行命令、环境变量或 VS Code 启动方式。
- 现有数据库或历史数据需要迁移。

```text
feat(api): 增加图片代理接口

兼容性：
- 不修改现有监控对象和趋势接口。
- 图片地址兼容历史数据库中的旧格式。
```

## 完整示例

```text
feat(backend): 增加 B 站图片代理接口

1. 仅允许代理 hdslb.com 图片域名。
2. 增加图片响应大小和超时限制。
3. 统一处理 B 站图片 HTTPS 地址。

测试：
- python -m unittest discover -s tests -v
```

```text
fix(chart): 修复趋势图横坐标重复日期

1. 24 小时范围显示日期和时间。
2. 7 天和 30 天范围自动隐藏重复日期标签。
3. 悬浮提示显示完整采样时间。

测试：
- pnpm run build
```

```text
docs(api): 补充趋势和图片代理接口说明
```

历史提交不重写；本规范从采用后的新提交开始执行。
