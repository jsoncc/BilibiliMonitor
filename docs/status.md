# 当前开发状态

更新时间：2026-09-13

## 当前版本

v0.1 本地 MVP 已完成：支持视频与 UP 主精确解析、后台快照采集、当前数据、历史趋势、监控恢复、立即采集和采集间隔设置。

UP 主监控范围为粉丝、投稿数和关注数；为避免平台访问限制，当前不采集“上次投稿日期”。历史数据库中的相关旧字段保留但不再读写。

v0.2 已完成首批数据管理能力：当前对象与全部对象的 CSV/JSON 导出、本地容量与快照摘要、最近采集日志查看，以及 SQLite WAL 并发读取优化。

已完成单对象专注模式：每个视频或 UP 主可独立选择要显示的指标；视频三连总量按点赞、投币、收藏计算，不新增采集或快照字段。

## 已知待完善

## 最新验证

- 后端测试通过：`python -m unittest discover -s tests -v`（8 项）。

- SQLite 可直接打开既有数据库，无需迁移。
